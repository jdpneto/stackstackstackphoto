## Pinned decisions

- **Module**: `:app` — AGP 8.7.x (compatible with Gradle 8.10.2 — verify; lower to 8.5/8.6 if the combo objects), Kotlin 2.0.21, compileSdk/target 35, **minSdk 33** (bible §5.2), Compose BOM (latest stable), `kotlinx-serialization-json` for index/sidecars, `androidx.exifinterface`. Package `com.jdpneto.stackstackstack`. Depends on `project(":stackengine")`.
- **Serialization back-compat parity**: the iOS Codable semantics are CONTRACT — missing optional keys decode as null/defaults (`Json { ignoreUnknownKeys = true }` + nullable fields with defaults); `ImageAdjustments` decodes via a serializable DTO that clamps/normalizes exactly like the Swift `init(from:)` (blendStrength `?? 1` clamped 0..1, quarterTurns mod 4, missing keys → 0/original). Index records use the SAME JSON field names as iOS (`resultFileName`, `frameCount`, `format`, `iso`, `shutterSeconds`, `createdAt`/`updatedAt` — iOS dates encode as Apple-epoch Double seconds; Android writes/reads the same representation: seconds since 2001-01-01 as Double, documented — cross-device library copy isn't a feature, but the format IS the recorded contract).
- **Processing dispatch**: coordinator serializes stacks on a single-thread executor/dispatcher (mirrors `processingTail`); the engine's `parallelMap` is executor-based and context-safe (PR #37).
- **Tests**: Robolectric for app-unit (store/coordinator-with-fakes/settings/encoder where Bitmap is needed — Robolectric's Bitmap supports JPEG encode; HEIC under Robolectric is NOT supported → encoder tests assert JPEG fully and gate HEIC assertions on runtime support exactly like the Intel-mac XCTSkip precedent). Emulator (API 35, `Medium_Phone_API_35`) for the end-to-end smoke, driven via adb/mobile-mcp by the controller in B4.
- **Capture mapping**: `Camera2CaptureService` = Camera2, sequential paced one-in-flight state machine on a single-thread executor (mirror stateQueue), `RAW_SENSOR` when `CameraCharacteristics` lists the RAW capability + a supported Bayer pattern, else JPEG fallback → decode at `fallbackDecodeLongEdge=1500` → `developed` payload (same constants/semantics as PR #33). Steadiness via `SensorManager` rotation-vector, same tolerance/gating semantics as `MotionSteadiness`. Compile-verified; the emulator exercises the fallback path live.

## Tasks

### Task B1: app scaffold + foundations (no UI)
Scaffold `:app` (AGP plugin in root build files; `gradle.properties` with android.useAndroidX). Port from iOS (read each Swift file first): `AppSettings` (SharedPreferences, 3 keys + format fallback), `StackRecord` + `LibraryStore` (full surface: save(result/reference/format/mode/frameCount/iso/shutter), record/loadAll/loadRaw-corrupt-preserve, delete/deleteAll batch, reconcileOrphans UUID-guarded, storageUsedBytes, originalData/referenceData/adjustments-with-stale-α-normalize/applyEdit-throws-on-missing), `ImageEncoder` (Bitmap JPEG/HEIC + ExifMetadata incl. Software/DateTimeOriginal POSIX + sRGB) + `ImageDecoder` (BitmapFactory, maxPixel ceiling never upscaling), `ResultRenderer` (record-format + referenceJPEG param), `CaptureEnvironment` (PowerManager thermal mapping: SEVERE→serious-equivalent, ≥CRITICAL→critical; BatteryManager; StatFs; same thresholds), `PhotoLibraryExporter` (MediaStore insert), `CaptureService` interface + `CapturedBurst`/`CaptureInfo` + `FakeCaptureService` (both moving-object and focus-bracket fakes, 1:1), `BurstSettings`/`ProControls`/`CaptureRecipe` (incl. FocusSweep + recipe(for:) + applying + usesSteadinessGate), `MotionSteadiness` (SensorManager; interface-extracted so tests fake it), `CaptureOrientation` (Display rotation → quarterTurns). Port the corresponding iOS test files under Robolectric (AppSettingsTests, LibraryStoreTests incl. legacy/format/reference/stale-α, CaptureRecipeTests, BurstSettingsTests, ImageEncoderTests w/ HEIC runtime-gated, ResultRendererTests, FakeCaptureServiceTests). `./gradlew :app:testDebugUnitTest` green. Commit.

Port `Camera2CaptureService` per the pinned mapping (one-in-flight, pacing, watchdog, steadiness gate, sweep lensPosition stepping via LENS_FOCUS_DISTANCE mapped from 0..1 across the device's focus range — document the diopter mapping; CaptureInfo from CaptureResult SENSOR_SENSITIVITY/EXPOSURE_TIME). Port CoordinatorTests (the whole file — fakes exist from B1; DevelopedFake; RawFakeWithInfo; thermal/storage/battery; export gating; HEIC fallback pairing; format honor; blend reference for smooth not depth; CaptureInfo lands). `./gradlew :app:testDebugUnitTest` green. Commit.

### Task B3: Compose UI + wiring

Depth gating + Standard-quality caption; Pro panel incl. Near/Far for depth; burst sliders; steadiness overlay; status line incl. environmentNote/photosExportNote; tap-to-focus + long-press AE/AF where Camera2 supports), GalleryScreen (grid + thumbnails), PhotoDetailScreen (zoom/rotate/share/edit/delete), EditorScreen (all sliders incl.
